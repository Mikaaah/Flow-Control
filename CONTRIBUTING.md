# Contributing

Include the exact Minecraft, NeoForge, Streams Reflowing and addon versions in bug reports.
Describe the wand mode, radius, vertical reach, controller placement, redstone and any overlapping regions.
Attach logs and screenshots where useful.

Build with Java 21 and the exact dependency jar documented in README.md.
Changes to flow behavior should include a meaningful integration regression check.
The integration harness is opt-in and must be run in a disposable world.
Do not commit third-party dependency jars, development worlds or credentials.

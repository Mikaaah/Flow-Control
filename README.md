# Flow Control

Shape Streams Reflowing water with the Flow Calibrator, current controllers, flow sensors, and mooring posts.

Version 1.0.2 requires Minecraft 26.3, Fabric Loader >=0.20.1, Fabric API, Java 25, and Streams Reflowing 2.17.3.

[CurseForge](https://www.curseforge.com/minecraft/mc-mods/flow-control-streams-reflowing-addon) · [Player guide](https://github.com/Mikaaah/Flow-Control/wiki)

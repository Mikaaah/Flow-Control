# Flow Control

Use the Flow Calibrator, Current Generator, and Stillwater Anchor to direct or calm Streams Reflowing water. Flow Sensors monitor currents, and Mooring Posts hold empty boats.

Flow Control 1.1.0 for Minecraft 1.21.1 requires NeoForge 21.1.219 or newer in the 21.1 series, Java 21, and Streams Reflowing 2.17.3 or newer. Create 6.0.10 or newer in the 6.0 series is optional.

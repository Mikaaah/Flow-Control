# Flow Control

Shape Streams Reflowing currents with the Flow Calibrator, Current Generator, and Stillwater Anchor. Flow Sensors and Mooring Posts help automate waterways and docks.

Flow Control 1.1.0 for Minecraft 1.20.1 requires Fabric Loader 0.18.4 or newer, Fabric API, Java 17, and Streams Reflowing 2.17.3 or newer.

Create Fabric 6.0.8 or newer is optional for the mechanical current generator.

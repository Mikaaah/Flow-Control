# Flow Control

Shape Streams Reflowing water with the Flow Calibrator, current controllers, flow sensors, and mooring posts.

Version 1.0.0 requires Minecraft 1.21.1, NeoForge [21.1.219,21.2), Java 21, and Streams Reflowing 2.17.1. Create [6.0.10,6.1) is optional.

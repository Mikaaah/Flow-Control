# Flow Control

Shape Streams Reflowing water with the Flow Calibrator, current controllers, flow sensors, and mooring posts.

Version 1.0.0 requires Minecraft 1.20.1, Forge [47.4,48), Java 17, and Streams Reflowing 2.17.1. Create [6.0.8,6.1) is optional.

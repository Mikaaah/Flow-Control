# Flow Control

Direct or calm Streams Reflowing water with a Flow Wand, Current Generator, or Stillwater Anchor.

Version 0.1.5 requires Minecraft 1.20.1, Forge [47.4,48), Java 17, and Streams Reflowing 2.15.2.

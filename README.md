# Flow Control

Redirect or calm Streams Reflowing currents with configurable controllers. Use the Flow Calibrator to inspect currents and link controls, Flow Sensors to read the water, and Mooring Posts to secure boats.

Flow Control 1.1.0 for Minecraft 26.1.2 requires Fabric Loader 0.18.4 or newer, Fabric API, Java 25, and Streams Reflowing 2.17.3 or newer.

# Flow Control

Shape Streams Reflowing water with the Flow Calibrator, current controllers, flow sensors, and mooring posts.

Version 1.0.3 requires Minecraft 1.21.11, NeoForge [21.11.48,21.12), Java 21, and Streams Reflowing >=2.17.3.

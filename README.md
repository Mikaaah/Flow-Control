# Flow Control

Direct or calm Streams Reflowing water with a Flow Wand, Current Generator, or Stillwater Anchor.

Version 0.1.5 requires Minecraft 1.21.1, Fabric Loader >=0.18.4, Fabric API, Java 21, and Streams Reflowing 2.15.2.

# Flow Control

Redirect or calm Streams Reflowing currents, measure flow with sensors, and tie up boats with mooring posts.

Flow Control 1.1.0 for Minecraft 26.1.2 requires Java 25, NeoForge 26.1.2.122 or later below 26.2, and Streams Reflowing 2.17.3 or newer.

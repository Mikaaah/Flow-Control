# Flow Control

Shape Streams Reflowing water with the Flow Calibrator, current controllers, flow sensors, and mooring posts.

Version 1.0.0 requires Minecraft 26.3, NeoForge [26.3.0.95,26.4), Java 25, and Streams Reflowing 2.17.1.

# Flow Control

Direct or calm Streams Reflowing water with a Flow Wand, Current Generator, or Stillwater Anchor.

Version 0.1.5 requires Minecraft 26.3, NeoForge [26.3.0.95,26.4), Java 25, and Streams Reflowing 2.15.2.

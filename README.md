# Flow Control

Shape or calm Streams Reflowing currents with the Flow Calibrator and water controllers. Use Flow Sensors to monitor the water and Mooring Posts to secure boats.

Flow Control 1.1.0 requires Minecraft 1.20.1, Forge 47.4 or newer in the 47 series, Java 17, and Streams Reflowing 2.17.3 or newer. Create 6.0.8 or newer in the 6.0 series is optional and powers the mechanical current generator.

# Flow Control

Redirect or calm Streams Reflowing currents, measure flow with sensors, and tie up boats with mooring posts.

Flow Control 1.1.0 for Minecraft 26.3 requires Java 25, NeoForge 26.3.0.95 or later below 26.4, and Streams Reflowing 2.17.3 or newer.

# Flow Control

Shape Streams Reflowing water with the Flow Calibrator, current controllers, flow sensors, and mooring posts.

Version 1.0.0 requires Minecraft 26.1.2, Fabric Loader >=0.18.4, Fabric API, Java 25, and Streams Reflowing 2.17.1.

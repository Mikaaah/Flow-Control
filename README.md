# Flow Control

Direct or calm water currents from Streams Reflowing with a Flow Wand, Current Generator, or Stillwater Anchor.

The 0.1.5 source on this branch requires Minecraft 1.21.1, NeoForge 21.1.219 or newer in the 21.1 series, Java 21, and Streams Reflowing 2.15.2.

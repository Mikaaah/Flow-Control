# Flow Control

Shape Streams Reflowing water with the Flow Calibrator, current controllers, flow sensors, and mooring posts.

Version 1.0.1 requires Minecraft 1.20.1, Fabric Loader >=0.18.4, Fabric API, Java 17, and Streams Reflowing 2.17.3. Create >=6.0.8 is optional.
